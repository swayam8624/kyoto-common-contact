One common broad-phase format

A point moves in a straight line past a fixed triangle. The broad phase sees only conservative bounds and stable IDs. A precise point-to-triangle distance check tells us which candidates are actually within the caller’s margin.

Shared record
PrimitiveBounds { id, kind, min[3], max[3] }   →   candidate pair [stableIdA, stableIdB]
The caller supplies δ = 0.12 for this experiment. Each primitive gets δ/2 padding. This retains all pairs within Euclidean distance δ and may retain more. The broad phase does not choose the margin.
