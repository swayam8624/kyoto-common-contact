# Prior art and novelty review before methods are named a contribution

The following are direct implementation and publication comparisons, not optional reading.

1. Official IPC Toolkit and continuous narrow phase: https://github.com/ipc-sim/ipc-toolkit
2. Official IPC Toolkit LBVH releases: https://github.com/ipc-sim/ipc-toolkit/releases
3. Incremental Potential Contact benchmarks: https://ipc-sim.github.io/
4. C-IPC mixed-dimensional contact: https://ipc-sim.github.io/C-IPC/
5. GAMMA connectivity-based culling: https://gamma-web.iacs.umd.edu/CBC/
6. GAMMA front-based parallel deformable collision: https://gamma-web.iacs.umd.edu/research/collision/
7. Topology-changing CCD by clustering: https://pmc.ncbi.nlm.nih.gov/articles/PMC4500942/
8. Solver-integrated deformation-aware BVH update, 2026: https://pubmed.ncbi.nlm.nih.gov/42672017/
9. LAMMPS neighbor-list skins / displacement bounds: https://docs.lammps.org/Developer_par_neigh.html
10. GAUGE benchmark families: https://huggingface.co/datasets/gaugewwxu/GAUGE-Dataset
11. NVIDIA Warp simulation repertoire: https://nvidia.github.io/warp/stable/index.html
12. ParaView rendering / scalar maps: https://docs.paraview.org/en/latest/UsersGuide/displayingData.html

Adaptive BVHs, hierarchy refits, collision front tracking, mixed motion regions, dynamic clustering, and temporal candidates are longstanding ideas. The thesis is NOT that these concepts have never been used.

Before publication create a claim matrix: claimed equation/property; closest prior method; source code difference; proof/limitation/counterexample; full paid timing; cross-validated scene results; independent reviewer. A method may be useful engineering without being a novel paper.

The reference dataset/method dates, licences, version hashes and reproducibility instructions must be pinned during the first fair comparison.
