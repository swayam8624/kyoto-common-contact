# Same-cloth collision and 3D mouse dragging

## Root cause

Previously, the physically coupled research simulator intentionally masked out triangle pairs belonging to the same cloth sheet. Its precise contact solver also skipped such pairs. Therefore, even an exhaustive broad phase could never prevent folds in one sheet from penetrating another part of that same sheet.

The new default permits same-sheet candidate pairs in SAP, global guarded SAP, fixed regional and online regional policies. The same contact solver is shared across every broad-phase comparison. This is an improvement to the PHYSICS TEST FIXTURE, not a new broad-phase novelty claim.

## Precise self-contact now implemented

- Preserve stable triangle and mesh-cell identities for all one-, two- and three-sheet configurations.
- Exclude immediate topological neighbors: triangle pairs occupying the same cell or any of the eight neighboring cells in the 12x12-cell fabric topology. Those pieces share bending/structural constraints and must not repel one another at rest.
- For NONLOCAL triangle pairs belonging to the SAME sheet, test all six vertex-face cases and all nine edge-edge closest features.
- Also test current segment-triangle piercing for folds that have already crossed a face, even if no vertex is within the thickness margin.
- Apply barycentric/inverse-mass positional correction to both features, respecting the existing per-vertex total correction budget and inelastic correction damping.
- Use the previous timestep's feature separation to orient degenerate contact normals, with a triangle-normal fallback if the previous separation is zero.
- Use a 0.070-unit self-contact thickness, strictly below the current 0.075-unit padded broad-phase search margin.

These tests are DISCRETE, not swept continuous time-of-impact calculations. Fast or pathological folds can still tunnel; this is not IPC, an intersection-free barrier guarantee or full robust CCD. Drag targets are deliberately rate-limited to reduce that risk.

## Grab and pull fabric in 3D

Run the corrected native research demo:

    git pull --ff-only origin main
    ./scripts/prepare_meeting.sh
    ./open_multicloth_demo.sh

Mouse controls:

- LEFT-CLICK on a visible fabric triangle: select the nearest ray-triangle intersection from the exact 3D scene camera. The application retains its barycentric weights so the grab applies to the actual picked point, not a randomly selected vertex.
- DRAG with left button down: move the grabbed point in a camera-facing plane through the original click location. You can lift, pull or fold the cloth rather than being restricted to a floor-plane movement.
- RELEASE left button: remove the grab constraint and let the cloth continue normally.
- RIGHT-DRAG or SHIFT+LEFT-DRAG: orbit the camera. Left-dragging an empty part of the scene also orbits; picking is disabled over the right-side evidence panel.
- S: enable/disable same-sheet self-collision. It is ON by default. Changing the collision masks invalidates the cached broad-phase certificates.
- G: show measured scientific statistics and the event log.

Gold lines mark the actual grabbed fabric point, cyan lines mark the desired mouse target, and a link displays solver tracking error. The attachment is mass-weighted and solved inside the same five XPBD-style structural/collision iterations as the physical scene. The target moves at most 0.055 world units per frame. Grab projections contribute to the inelastic previous-position correction, preventing them from injecting excessive instantaneous velocity.

## Independent tests

The ordinary Linux and macOS headless C++ tests validate:

1. Camera center-ray picking and frontmost two-sided triangle intersections; normalized barycentric coordinates, clean miss handling and correct camera-facing drag plane.
2. A deliberately folded one-cloth sheet generated by displacing a movable patch over a nonlocal part of the same mesh. The same-sheet precise pass must produce positive physical corrections, while shared-neighbor pairs are filtered. Disabling self collision must remove those self corrections.
3. An interactive mass-weighted grab through 78 changing target frames and 18 release frames, with independent SAP and ONLINE regional broad phases giving identical particle coordinates (maximum difference below 1e-8). The fabric must visibly move and remain within conservative motion/structural strain limits.
4. All previous strict broad-phase coverage and multi-cloth tests, the 480-frame stability regression, the external Bullet 3D comparison and Mac native viewer build remain enabled.

Headless CI does not guarantee native mouse handling visually works on the user's exact Mac screen. The native app builds under macOS CI, but it must be exercised locally for final visual validation.

## Research boundary and benchmark fairness

Enabling self collision changes the physics work distribution, candidate counts and precise-check workload. It is an important additional stress case for an adaptive broad phase, but older inter-sheet-only timing plots cannot be presented as if they were measured with self-collision enabled. Rerun the preparation script on the updated code.

The algorithm under research continues to be candidate maintenance and region adaptation, NOT a newly invented self-contact solver. Same-sheet vertex/face and edge/edge checks and discrete triangle-piercing correction are established geometric techniques.
