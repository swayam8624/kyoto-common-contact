Interpretation boundary

This prototype compares two conservative candidate generators for spheres. It does not implement or validate IPC, OGC, PBD/XPBD, or CCFR.

About the prototype

The C++ core owns the simulation state and computes candidate pairs, sphere contacts, elastic response, and contact islands. The swept mode uses conservative linear swept AABBs and analytic sphere-sphere time of impact for this demo geometry.

Broad-phase timings are measured locally and should be treated as diagnostics, not benchmark claims. Swept bounds here cover linear sphere translation; mesh rotation/deformation and external-method integration are not implemented.
